# ADR-NNN · Titulo

- **Estado:** Propuesta | Aceptada | Sustituida por ADR-NNN

## Decision

Que se hace, en una o dos frases.

## Consecuencias

Que se gana, que se pierde y que queda pendiente.

## Cuando reabrirla
